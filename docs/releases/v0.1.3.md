파일 찾기에 like 검색과 이클립스 단축키를 더한 버전입니다.

## 새 기능

- **파일 찾기 like 검색**: 검색어에 `*`(아무 글자들)나 `?`(한 글자)가 있으면 이클립스 Open Resource처럼 파일 이름 패턴으로 찾습니다.
  - 예: `*edu*`는 이름에 edu가 들어간 파일, `Pt*Service`는 Pt로 시작해 Service가 들어간 파일. 대소문자는 가리지 않고, 끝에는 `*`가 붙은 것으로 봅니다.
  - `/`를 넣으면 경로에서 찾습니다 (예: `mapper/*edu*`).
  - 찾은 파일 수가 창 아래에 나옵니다. 파일 탐색 화면의 검색창도 같습니다.
- **Ctrl+Shift+R로 파일 찾기**: 이클립스와 같은 키입니다. `Ctrl+P`도 그대로 됩니다.

## 고친 것

- **F5 새로고침이 보이게**: F5를 눌러도 표시가 없어 동작하지 않는 것처럼 보였습니다. 이제 툴바의 새로고침 아이콘이 돌고, 보고 있는 diff와 작성자 목록까지 다시 읽습니다.
- **Ctrl+R도 새로고침**: 앱 화면 전체가 다시 읽혀 보던 곳이 처음으로 돌아가지 않게 했습니다.
- 한글 입력 상태에서도 `Ctrl+Shift+R`, `Ctrl+P`, `Ctrl+W` 단축키가 동작합니다.

## 설치

- 아래 `NanoGit_0.1.3_x64-setup.exe`를 받아 실행하면 이전 버전 위에 그대로 설치됩니다. 설정과 열어 둔 저장소는 그대로입니다.
- NanoGit이 실행 중이면(트레이 포함) 설치할 때 닫으라는 안내가 나옵니다.
- PC에 [Git for Windows](https://git-scm.com/download/win) 2.30 이상이 있어야 합니다.
- 코드 서명을 하지 않은 설치 파일이라 Windows SmartScreen이 경고할 수 있습니다. "추가 정보 → 실행"을 누르세요.
