작은 화면 수정 버전입니다.

## 고친 것

- **활동 화면의 일시를 한 줄로**: 하루가 지난 기록의 일시("11월 20일 10:20")가 두 줄로 접혀 그 줄만 높아지고, 한 화면에 보이는 기록이 줄던 문제를 고쳤습니다. 파일 목록의 시각도 한 줄로 나옵니다.

## 설치

- 아래 `NanoGit_0.1.1_x64-setup.exe`를 받아 실행하면 0.1.0 위에 그대로 설치됩니다. 설정과 열어 둔 저장소는 그대로입니다.
- NanoGit이 실행 중이면(트레이 포함) 설치할 때 닫으라는 안내가 나옵니다.
- PC에 [Git for Windows](https://git-scm.com/download/win) 2.30 이상이 있어야 합니다.
- 코드 서명을 하지 않은 설치 파일이라 Windows SmartScreen이 경고할 수 있습니다. "추가 정보 → 실행"을 누르세요.
