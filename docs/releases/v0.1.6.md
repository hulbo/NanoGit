파일 내용으로 찾기(Ctrl+H)와, 파일 이력에서 커밋하지 않은 지금 파일을 함께 보는 버전입니다.

## 새 기능

- **내용으로 찾기 (`Ctrl+H`)**: IntelliJ의 Find in Files처럼 작업 트리의 파일 내용에서 찾습니다. 툴바의 "내용 찾기" 버튼으로도 엽니다.
  - 위에는 결과 목록(맞은 글자 강조, 파일 이름과 줄 번호), 아래에는 그 파일의 미리보기가 나오고 맞은 줄이 강조됩니다.
  - 대소문자(`Alt+C`)·단어(`Alt+W`)·정규식(`Alt+X`)을 켜고 끌 수 있고, 파일 마스크(`*.java, *.xml`, 앞에 `!`를 붙이면 빼기)로 좁힙니다.
  - 커밋하지 않은 새 파일도 찾고, .gitignore로 무시한 파일과 이진 파일은 뺍니다.
  - 글자를 고른 채 누르면 그 글자로 찾고, 다시 열면 마지막 검색이 남아 있습니다.
  - Enter(또는 더블클릭)로 고르면 `Ctrl+Shift+R`과 같은 파일 이력 화면에서 맞은 줄을 보여 줍니다.
- **파일 이력 맨 위에 지금 파일**: 파일이 바뀌어 있으면(수정·스테이지·새 파일·충돌) 이력 맨 위에 "커밋하지 않은 변경 (지금 파일)" 줄이 커밋과 다른 모양(파란 띠, 점선, 연필 아이콘)으로 나오고, 처음부터 골라져 있습니다.
  - "변경 내용"은 마지막 커밋 → 지금 파일, "이 버전 내용"과 Blame은 지금 파일을 보여 줍니다.
  - 커밋 하나를 Ctrl+클릭하면 그 커밋과 지금 파일을 비교합니다.
  - 파일이 바뀌면 바로 다시 읽고, 커밋하면 그 줄 대신 새 커밋이 목록에 들어옵니다.

## 바뀐 점

- **파일 찾기(`Ctrl+Shift+R`) 와일드카드에 경로 포함**: `*isbm*appli*.yml`처럼 쓰면 이름뿐 아니라 경로까지 맞춰 찾습니다. 이름에서 맞은 파일이 먼저, 경로에서 맞은 파일이 그다음에 나옵니다.
  - `/`는 사이 폴더를 건너뛸 수 있어 `*link/appli*yml`로 `apps/link/src/main/resources/application.yml`을 찾습니다.
- 파일 우클릭 메뉴의 "이력 조회"에 붙어 있던, 실제로는 동작하지 않던 `Ctrl+H` 표시를 지웠습니다.

## 설치

- 0.1.5를 쓰고 있으면 바탕화면의 **"NanoGit 업데이트"** 바로가기를 누르세요. 바로 받아 설치하고 다시 켜집니다. 상태 표시줄의 "새 버전" 버튼(또는 설정의 "업데이트 확인")도 됩니다.
- 0.1.4는 "새 버전" 버튼으로 업데이트하세요.
- 처음 설치하거나 0.1.3 이하에서 올리려면 아래 `NanoGit_0.1.6_x64-setup.exe`를 받아 실행하세요. 설정과 열어 둔 저장소는 그대로입니다.
- PC에 [Git for Windows](https://git-scm.com/download/win) 2.30 이상이 있어야 합니다.
- 코드 서명을 하지 않은 설치 파일이라 Windows SmartScreen이 경고할 수 있습니다. "추가 정보 → 실행"을 누르세요.
