AI(Claude Code 등)가 하는 git 작업을 지켜보는 가벼운 git 모니터, NanoGit의 첫 버전입니다. 화면은 소스트리(SourceTree)와 같은 구성입니다.

## 설치

- 아래 `NanoGit_0.1.0_x64-setup.exe`를 받아 실행합니다. 관리자 권한 없이 사용자 폴더에 설치됩니다.
- PC에 [Git for Windows](https://git-scm.com/download/win) 2.30 이상이 있어야 합니다. NanoGit은 설치된 git과 그 설정·인증을 그대로 씁니다.
- 코드 서명을 하지 않은 설치 파일이라 Windows SmartScreen이 경고할 수 있습니다. "추가 정보 → 실행"을 누르세요.
- Windows 10/11 (WebView2)

## 지켜보기

- **실시간 감시**: AI가 파일을 고치거나 커밋·push하면 1초 안에 화면에 반영됩니다. 바뀌는 저장소 탭은 점이 깜빡입니다.
- **활동 타임라인**: reflog로 커밋·amend·reset·전환·병합·rebase·push·fetch를 시간순으로 보여 줍니다. reset·강제 push로 버려진 커밋은 빨간 경고와 함께 그 자리에서 봅니다.
- **Push 대기**: IntelliJ push 대화상자처럼 아직 push하지 않은 커밋과 바뀐 파일·diff를 보여 줍니다.
- **파일 이력**: 이름 변경 추적, 두 버전 비교, 그 버전 내용, blame, 작업 트리와 비교, 선택한 줄만의 이력(`git log -L`)을 지원합니다.
- **저장소 요약**(`Ctrl+0`): 열어 둔 모든 저장소를 카드로 보여 주고, 모든 저장소의 활동을 한 줄로 합칩니다.
- **Windows 알림·트레이 상주**: 창을 닫아도 트레이에서 감시를 계속하고, 커밋·push·위험한 작업을 알림으로 알립니다.

## 직접 조작

- 파일·헝크 단위 스테이지·언스테이지·버리기
- 커밋(amend, 커밋 후 push)
- Push 대기에서 확인하고 push, pull
- 브랜치·병합·stash·태그, cherry-pick·revert
- 병합 충돌 계속·중단
- 버리는 파일은 휴지통에 남고, 강제 push는 `--force-with-lease`만 씁니다.
- 지켜보기만 하려면 설정에서 **감시 전용 모드**를 켜세요. 조작 버튼이 사라집니다.
