바탕화면 바로가기 하나로 업데이트하는 버전입니다.

## 새 기능

- **"NanoGit 업데이트" 바로가기**: 바탕화면의 이 바로가기를 누르면 묻지 않고 바로 새 버전을 받아 설치하고, NanoGit이 다시 켜집니다.
  - NanoGit이 트레이에 떠 있을 때 눌러도, 꺼져 있을 때 눌러도 됩니다. 새 버전이 없으면 "이미 최신 버전입니다"라고 알려 줍니다.
  - 이 버전으로 업데이트한 뒤(또는 설치한 뒤) 처음 켜질 때 바탕화면에 한 번 만듭니다.
  - 지우면 다시 만들지 않습니다. 설정에서 "바탕화면에 NanoGit 업데이트 만들기"로 다시 만들 수 있습니다.
  - NanoGit을 제거하면 이 바로가기도 함께 지웁니다.

## 설치

- 0.1.4를 쓰고 있으면 NanoGit의 상태 표시줄에 뜨는 "새 버전" 버튼(또는 설정의 "업데이트 확인")으로 업데이트하세요.
- 처음 설치하거나 0.1.3 이하에서 올리려면 아래 `NanoGit_0.1.5_x64-setup.exe`를 받아 실행하세요. 설정과 열어 둔 저장소는 그대로입니다.
- PC에 [Git for Windows](https://git-scm.com/download/win) 2.30 이상이 있어야 합니다.
- 코드 서명을 하지 않은 설치 파일이라 Windows SmartScreen이 경고할 수 있습니다. "추가 정보 → 실행"을 누르세요.
