앱 안에서 업데이트하는 기능을 넣은 버전입니다. 이번 한 번만 손으로 설치하면, 다음 버전부터는 NanoGit이 직접 받아서 설치합니다.

## 새 기능

- **앱 안 업데이트**: 켠 뒤 15초, 그다음 6시간마다 새 버전이 있는지 봅니다.
  - 새 버전이 있으면 알림과 상태 표시줄 오른쪽의 "새 버전" 버튼이 뜹니다.
  - 버튼을 누르면 릴리스 노트를 보여 주고, 받는 동안 진행률이 나옵니다. 작은 설치 창이 뜬 뒤 NanoGit이 다시 켜지고 "업데이트했습니다"를 알립니다.
  - 받은 설치본은 서명을 확인한 뒤에만 설치합니다.
  - 커밋·push 같은 조작이 진행 중이면 업데이트를 미룹니다.
  - 설정에서 "업데이트 확인"으로 바로 볼 수 있고, 자동 확인은 끌 수 있습니다.
- **파일 이름 복사**: 파일 우클릭 메뉴에 "파일 이름 복사"를 넣었습니다 (경로 없이 이름만).

## 설치

- 아래 `NanoGit_0.1.4_x64-setup.exe`를 받아 실행하면 이전 버전 위에 그대로 설치됩니다. 설정과 열어 둔 저장소는 그대로입니다.
- NanoGit이 실행 중이면(트레이 포함) 설치할 때 닫으라는 안내가 나옵니다.
- PC에 [Git for Windows](https://git-scm.com/download/win) 2.30 이상이 있어야 합니다.
- 코드 서명을 하지 않은 설치 파일이라 Windows SmartScreen이 경고할 수 있습니다. "추가 정보 → 실행"을 누르세요.
